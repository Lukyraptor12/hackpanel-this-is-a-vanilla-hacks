HACK PANEL (Fabric 1.21.1)
Compilar:  gradle build      (necesita JDK 21 y Gradle 8.8+; si tienes el wrapper: ./gradlew build)
Resultado: build/libs/hackpanel-1.0.0.jar  -> copiar a .minecraft/mods junto con Fabric Loader + Fabric API.
Uso: Right Shift abre el panel. R = Click TP (si esta activado). TP a coordenadas usa /tp (requiere trucos/OP).
